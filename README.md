## 🚀 Featured Projects

### 🏆 [EAURACLE](https://github.com/JosaphatAdj) *(W4F 2026 Gold Prize Winner)*
> Predictive water management and early warning concept combining IoT sensors in the Ouémé basin with satellite data and predictive machine learning models. Awarded 1st place by UNESCO ICIREWARD (Montpellier).

### 🤖 [ROBONEST](https://github.com/JosaphatAdj) *(Google-Kaggle Capstone 2025)*
> Autonomous multi-agent software architecture for robot fleet surveillance: automatic diagnostics, self-repair triggering, critical alert escalation to human operators, and solution management via the A2A protocol.

### 🌸 [ANONTCHIGAN](https://github.com/JosaphatAdj) *(Breast Cancer Screening Platform, 2025)*
> Web platform combining tabular ML prediction, image classification (Deep Learning), and an interactive RAG chatbot for breast cancer awareness, self-examination education, and screening center guidance.

### 🧮 [PINNs Exploration](https://github.com/JosaphatAdj) *(Personal Research)*
> Benchmarking Deep Learning-based solvers (Physics-Informed Neural Networks) against classical numerical methods (FEM/FDM) for Partial Differential Equations (heat, wave, and Navier-Stokes equations).
